# Directory images

`icon.svg` is an original calendar symbol for field-kit.

`screenshot-plan.jpg` and `screenshot-ledger.jpg` show hand-written, fictional examples in a local browser preview.
They illustrate the output structure. They are not screenshots of ChatGPT, proof of a test pass or real event results.
Each image carries a fictional-example label. Neither contains guest names or test-run output.

The plan image shows four sample weeks. A full field-kit plan covers 13 weeks.
The ledger image shows two fictional events and keeps sales outcomes separate from attendance.

Both screenshots are JPEG files, 2908 by 1754 pixels, below 5 MiB each.
The icon has a 512 by 512 viewBox. All three files use the repository's MIT License.
